# Lista Zadań

Lista Zadań to prosta aplikacja do zarządzania zadaniami stworzona w React i Tailwind CSS. Umożliwia użytkownikom dodawanie zadań z terminem wykonania, edytowanie zadań, usuwanie zadań oraz zapisywanie i wczytywanie zadań z pliku JSON.

## Funkcje

- **Dodaj zadanie**: Dodaj nowe zadanie z terminem wykonania.
- **Edytuj zadanie**: Edytuj treść i termin wykonania istniejącego zadania.
- **Usuń zadanie**: Usuń zadanie z listy.
- **Zapisz zadania**: Zapisz wszystkie zadania do pliku JSON.
- **Wczytaj zadania**: Wczytaj zadania z pliku JSON.

## Technologie

- **React** (v18) - Do budowy interfejsu użytkownika oraz zarządzania stanem.
- **Tailwind CSS** - Do stylowania aplikacji.
- **JavaScript** (ES6+) - Do logiki aplikacji.

## Jak korzystać

1. **Dodaj zadanie**:
   - Wpisz treść zadania w polu "Nowe zadanie".
   - Wybierz datę jako termin wykonania.
   - Kliknij przycisk "➕ Dodaj", aby dodać zadanie.

2. **Edytuj zadanie**:
   - Kliknij przycisk "✏️ Edytuj" obok zadania, które chcesz edytować.
   - Zaktualizuj treść zadania oraz termin wykonania.
   - Kliknij "💾 Zapisz", aby zapisać zmiany.

3. **Usuń zadanie**:
   - Kliknij przycisk "🗑️ Usuń", aby usunąć zadanie.

4. **Zapisz zadania**:
   - Kliknij przycisk "💾 Zapisz zadania", aby zapisać wszystkie zadania do pliku JSON.

5. **Wczytaj zadania**:
   - Kliknij przycisk "Wybierz plik", aby wczytać zadania z pliku JSON.
